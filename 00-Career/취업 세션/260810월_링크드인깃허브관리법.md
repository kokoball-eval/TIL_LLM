1. 취업 지원 세션 내용

## 평가자의 서류 검토 동선
  - 서류 1건당 평균 검토 시간 2분, 깃허브 접속 후 첫인상 결정까지 단 30초 소요
  - `이력서 링크 클릭` → `프로필 화면 확인` → `대표 핀 레포 선택` → `README 스캔` → `커밋 히스토리 및 코드 확인`

## 취준생의 주요 오해와 진실
  - 잔디(기여 그래프): 양보다 내용이 중요하며, 단순 초록색 자체는 핵심 평가 요소가 아님 (참고용)
  - 레포 개수: 평가자는 다 볼 시간이 없으므로 1~2개의 선별된 대표 레포(Pin)면 충분함
  - 링크드인: 신입이라도 업계 동향 수집, 리크루터 접점 확보, 퍼스널 브랜딩의 통로로 유용함

## 포트폴리오가 되는 깃허브 레포 & README
  - 선별 기준: 완성도(배포/실행 가능), 직무 연관성, 문제 해결 스토리가 담긴 레포 1~2개 핀 고정 
  (나머지는 과감히 Private 전환)
  - README 작성 원칙: 
  코드를 열기 전 읽히는 얼굴이며, 두괄식(역피라미드) 구조와 F-패턴 스캔을 고려하여 핵심(무엇을, 왜)을 최상단에 배치

## README 필수 구성 5단계
`01. 무엇을/왜` → `02. 데모/스크린샷` → `03. 기술적 의사결정` → `04. 결과/성과(수치)` → `05. 실행 방법`
  - 팀 프로젝트 명시: '팀이 했다'가 아닌 '내가 한 역할'과 PR 링크, 개인 회고, 커밋 이메일 설정을 명확히 정리

## 신입을 위한 링크드인 최소 세팅
  - 프로필 필수 5요소: 사진, 헤드라인, About(방향성 3~5문장), 경력/교육, 스킬 & 링크
  - 검색되는 헤드라인: 단순 취준생 문구 대신 `직무 + 기술 + 증거` 키워드로 구성 
  (예: "LLM 서비스 개발자 지망 | Python RAG·팀 프로젝트 3회")
