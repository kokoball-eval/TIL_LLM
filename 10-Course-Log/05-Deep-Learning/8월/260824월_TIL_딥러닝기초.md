## 3. 오늘 배운 핵심 내용

### 1. 손실 함수(Loss Function)의 역할 및 Reduction
* **손실 함수의 역할**: 예측값과 정답 간의 차이를 미분 가능한 단일 스칼라(Scalar)로 변환하여 역전파(backward) 기준점을 제공함

* **Reduction 옵션별 동작**:
  * `'none'`: 배치 내 개별 샘플/원소의 Loss를 텐서 형태로 그대로 유지 (에러 분석 및 샘플별 가중치 적용 시 활용)
  * `'mean'`: 배치 내 모든 오차의 평균을 반환하며, 배치 크기가 변해도 기울기 스케일을 일정하게 유지 (기본값)
  * `'sum'`: 배치 내 오차의 총합을 반환하며, 데이터 개수에 비례하여 스케일이 커짐

---

### 2. 문제 유형별 손실 함수 및 입출력 규격
* **회귀 (Regression)**:
  * 모델 출력: (B, 1) 형태의 연속적인 실수값
  * Target 규격: (B, 1) 형태, torch.float32 타입
  * 추천 함수: nn.MSELoss() (예측값과 타깃의 Shape 일치 확인 필수)

* **이진 분류 (Binary Classification)**:
  * 모델 출력: (B, 1) 형태의 단일 Logit
  * Target 규격: (B, 1) 형태, torch.float32 타입 (0.0 또는 1.0)
  * 추천 함수: nn.BCEWithLogitsLoss() (모델 끝에 별도의 Sigmoid 레이어를 추가하지 않음)

* **다중 분류 (Multiclass Classification)**:
  * 모델 출력: (B, C) 형태의 클래스별 Logits
  * Target 규격: (B,) 형태, torch.long 타입 (원-핫 벡터가 아닌 0부터 C-1까지의 클래스 인덱스)
  * 추천 함수: nn.CrossEntropyLoss()

* **다중 레이블 (Multilabel Classification)**:
  * 모델 출력: (B, L) 형태의 레이블별 Logits
  * Target 규격: (B, L) 형태, torch.float32 타입
  * 추천 함수: nn.BCEWithLogitsLoss() (각 레이블을 독립적인 이진 문제로 동시 처리)

---

### 3. Optimizer와 Learning Rate
* **SGD (Stochastic Gradient Descent)**: 현재 스텝의 기울기 반대 방향으로 가중치를 단순 업데이트 (새 파라미터 = 기존 파라미터 - lr * grad)

* **Adam**: 1차 모멘트(기울기 방향 평균)와 2차 모멘트(기울기 크기 제곱 평균)를 반영해 파라미터별 이동량을 적응적으로 조절

* **Learning Rate (lr)**:
  * 지나치게 작은 경우: 손실 감소 속도가 매우 느려 제한된 스텝 내 수렴 실패 가능
  * 지나치게 큰 경우: 최적점을 지나치며 진동하거나 Loss가 발산(Inf/NaN)

---

### 4. PyTorch 파라미터 업데이트 5단계 흐름

```python
# 1. Gradient 초기화 (기울기 누적 방지)
optimizer.zero_grad()

# 2. 순전파 (Forward Pass)
outputs = model(inputs)

# 3. 손실 계산 (Loss Calculation)
loss = criterion(outputs, targets)

# 4. 역전파 (Backward Pass: 파라미터의 .grad에 기울기 저장)
loss.backward()

# 5. 가중치 갱신 (Parameter Update)
optimizer.step()
