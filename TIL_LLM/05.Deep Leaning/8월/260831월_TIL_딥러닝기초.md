## 3. 오늘 배운 핵심 내용

### 12장. CNN 모델 설계 및 종합 실습

1) 12-1강. 
CNN 모델 설계 기준: CNN 설계는 입력 채널(in_channels)과 출력 클래스 수에 맞춰 Conv2d -> ReLU -> MaxPool2d 블록을 쌓으며, 처음에는 작은 베이스라인 모델로 시작해 출력 shape를 검증하는 것이 좋습니다.

2) 12-2강. 
CNN 학습 파이프라인 구성: Dataset, DataLoader, Model, CrossEntropyLoss, Optimizer를 유기적으로 연결하고, 학습 모드(train)와 평가 모드(eval 및 no_grad)를 엄격히 분리하여 에포크별 지표를 기록합니다.

3) 12-3강. 
GPU Memory 기초: 모델과 데이터 텐서는 반드시 같은 디바이스에 올려야 하며, CUDA OOM 발생 시 배치 크기 축소, .item()을 통한 메모리 누수 방지, validation 시 torch.no_grad() 적용으로 해결합니다.

4) 12-4강. 
필터 수/커널 크기 변경 실험: 단일 변수 통제 원칙에 따라 필터 수나 커널 크기를 한 번에 하나씩만 변경하며 파라미터 수와 성능 변화를 체계적인 config로 비교합니다.

5) 12-5강. 
MLP baseline 준비: 이미지를 1차원으로 펼치는 MLP 대조군을 만들어 동일한 학습 함수로 훈련시킴으로써, CNN의 2D 공간 특징 보존 능력을 공정하게 증명할 기준점을 마련합니다.

6) 12-6강. 
MLP vs CNN 성능 비교: 비슷한 파라미터 수 조건에서 공간 구조를 온전히 보존하는 CNN이 시작부터 픽셀을 일렬로 펼치는 MLP보다 이미지 분류에서 우수함을 동일 조건 실험으로 확인합니다.

7) 12-7강. 
실험 결과 리포팅: 단순 정확도 수치에 그치지 않고 계층별 텐서 형태 변화(shape trace), 학습 곡선(loss curve), 실험 조건 및 한계점을 포함한 과학적 실험 보고서를 작성합니다.

8) 12-8강. 
CNN 종합 실습 제출: 소스코드, 그래프 출력물, 최적 가중치 체크포인트(.pt), 마크다운 보고서를 분리 패키징하고, Test set은 validation 기반 모델 선정이 끝난 뒤 마지막에 단 1회만 평가합니다.

### 13장. Sequence Data와 순환 신경망 (RNN/LSTM)

1) 13-1강. 
Sequence Data와 Hidden State: 시퀀스 데이터는 (batch_size, sequence_length, input_size) 구조를 가지며, RNN은 이전 시점의 요약 메모장인 Hidden State를 다음 시점으로 순차 전달하며 문맥을 학습합니다.

2) 13-2강. 
RNN forward 흐름과 출력 shape: 시퀀스 분류는 전체 output 중 마지막 유효 시점의 Hidden State를 선별해 Linear 층에 연결하며, 패딩이 포함된 배치는 lengths - 1 인덱스를 안전하게 지정해야 합니다.

3) 13-3강. 
장기 의존성과 경사 소실: 시퀀스가 길어지면 역전파 시 그래디언트가 반복 곱셈되어 사라지는 경사 소실이 발생하며, 그래디언트 폭주는 clip_grad_norm_을 통해 완화합니다.

4) 13-4강. 
LSTM Gate와 Cell State: 정보가 손실 없이 흐르는 덧셈 기반 고속도로인 Cell State와 3개의 게이트(Forget, Input, Output)를 도입해 장기 기억력을 보존하고 경사 소실을 해결합니다.

5) 13-5강. 
Transformer 이전 모델의 한계 연결: RNN과 LSTM은 단어를 순서대로 계산해야 하는 순차 처리 특성상 GPU 병렬 연산이 불가능하고 초장문 처리에 한계가 있어 트랜스포머 구조가 등장하는 배경이 되었습니다.
