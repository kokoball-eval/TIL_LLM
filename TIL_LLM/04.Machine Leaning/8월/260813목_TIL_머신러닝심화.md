## 3. 오늘 배운 것

1) 편향-분산 트레이드오프 & 곡선 진단
* **편향(Bias) vs 분산(Variance)**
  - **편향**: 표현력 부족으로 한쪽으로 빗나감 (과소적합).
  - **분산**: 훈련 데이터 잡음까지 외워 예측이 흔들림 (과적합).
  - **비가약 오차(σ²)**: 데이터 자체의 잡음. 모델을 바꿔도 줄일 수 없음.

* **진단 도구**
  - **학습곡선**: **데이터 양**을 바꿔가며 대표 데이터 수집 가치 진단.
  - **검증곡선**: **하이퍼파라미터 하나**를 바꿔가며 최적의 모델 복잡도 설정.

* **진단 결과 및 처방**
  - **고편향 (둘 다 점수 낮음, Gap 작음)**: 특성 추가, 모델 복잡도 UP, 규제 DOWN *(데이터 수집 효과 없음)*
  - **고분산 (Train만 높음, Gap 큼)**: 그룹 누수 점검, 모델 복잡도 DOWN, 규제 UP, 대표 데이터 수집

2) 규제 (L1, L2, ElasticNet)
* **원리 및 핵심**: Loss에 계수 벌점(α)을 추가해 과적합 억제. 스케일링을 위해 `StandardScaler` + `Pipeline` 필수.
* **모델별 차이**
  - **Ridge (L2)**: 계수를 부드럽게 축소. 상관관계 높은 특성을 **함께 유지**.
  - **Lasso (L1)**: 불필요한 계수를 **정확히 0**으로 만듦. 변수 자동 선택 (모델 경량화).
  - **ElasticNet**: L1 + L2 혼합. 변수 선택과 상관 그룹 유지를 동시에 도모.
* **실무 프로세스**: 동일 5-Fold CV 평가 → 실질적 동률(Practical Tie) 시 운영 목적(특성 유지 vs 경량화)으로 모델 확정 → Sealed Test 1회 평가.
