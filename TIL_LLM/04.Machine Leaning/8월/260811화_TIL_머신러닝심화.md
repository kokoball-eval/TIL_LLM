## 1. 금일 학습 총평
- 오늘은 머신러닝의 기본 개념 위주의 학습이었으며, 개강 전 사전 학습(Step 2 강의)을 통해 접했던 내용이 포함되어 있어 이론적 흐름은 나름 익숙했음.
- 그러나 실습 문제와의 난이도 격차가 커서, 개념을 실제 문제의 해결 방식으로 깔끔하게 연결하는 데에는 어려움이 있었음.

## 2. 오늘 배운 것

### 1) 머신러닝 문제 유형 및 데이터 분리
- **지도학습 vs 비지도학습**: 정답(Label) 유무에 따른 학습 방식 구분.
- **4대 문제 유형**: 회귀(Regression), 분류(Classification), 군집화(Clustering), 차원축소(Dimensionality Reduction).
- **데이터 분리**: Train / Valid / Test 세트의 각각의 역할 정의 및 K-Fold 교차검증을 통한 모델 일반화 검증.

### 2) 평가지표(Metrics)의 이해
- **오차 기반 회귀 지표**: MAE, MSE, RMSE, $R^2$의 특성 및 차이점.
- **비용 구조 기반 분류 지표**: Accuracy, Precision, Recall, F1-Score, ROC-AUC, AP의 개념 및 실제 비즈니스 문제별 적용 기준.

### 3) 5대 핵심 기본 모델
- **선형 모델 (Linear / Logistic Regression)**: 직관적이고 해석력이 높으나 선형성 가정이 필요함.
- **KNN**: 거리 기반 알고리즘으로 직관적이나 데이터 규모에 민감함.
- **결정트리 (Decision Tree)**: 시각화가 쉽고 전처리 요구사항이 적으나 과적합 위험이 존재함.
- **K-Means**: 대표적인 비지도 군집화 모델.
- **PCA**: 고차원 데이터를 핵심 성분 중심으로 축소하는 기법.
- **전처리 조건**: 각 알고리즘별 스케일링, 인코딩, 이상치 처리 등의 전처리 요구조건 파악.

### 4) 데이터 누수(Data Leakage) 방지 및 모델 선택 기준
- **Data Leakage 방지**: 전처리 시점 관리(Train 기준 fit) 및 Pipeline 활용을 통한 평가 부풀림 방지.
- **Baseline 모델 선정**: 비즈니스 제약과 문제 성격에 맞는 초기 모델 선택 가이드라인.

## 3. 개선해야 할 점

- 추후 학습 시 문장 해석 능력을 키우고 실무 적용 원리를 파악하여, 실습 문제 풀이로 스무스하게 연결될 수 있도록 지속적인 복습이 필요함.
